# Structured Simulation Log and Zero-Dependency Typed i18n

Simulation and store state store language-agnostic identifiers and structured combat log descriptors (`Phrase` values constructed via `phrase(id, params)` and projected onto units via `projectUnit` / `relabelCatalogs`) rather than pre-formatted localized strings, and all user-facing text is resolved at projection/render time through a zero-dependency typed `src/i18n/` module (`cs-lexicon.ts`, `cs-messages.ts`, `cs-ui.ts`, and `csDamageSources` for non-firearm damage attributions). Because Slavic languages (such as Czech) require grammatical case inflection (nominative, genitive, dative, accusative, vocative, locative, instrumental) and 3-way pluralization rules (`1`, `2–4`, `5+`) that depend on both the sentence template and the unit identity, typed locale formatter functions provide compile-time safety without external runtime dependencies while allowing locale packs to re-project existing combat log history, catalogs, unit statuses, and epilogues cleanly.
